# 🎵 Vibe — Music Player UI

---

📌 Project Overview

Vibe (Music Player UI) is a web-based project developed using HTML, CSS, and JavaScript.

The project was created to apply the concepts learned during the Web Development Training Program and to gain practical experience in designing and developing an interactive website.

The project focuses on recreating a Spotify-style music player interface, where users can browse a library of 20+ songs, search for tracks, and control playback (play, pause, next, previous, shuffle, repeat, seek, and volume) — all through a fully interactive front-end UI.

🎨 Design Decisions

Explain some important design decisions you made.

Color Scheme:
A dark theme (near-black backgrounds: #000000, #121212, #181818) with a signature green accent (#1DB954) was used, matching the familiar look and feel of popular music streaming apps. The dark palette keeps focus on album art and content while the green accent highlights active/interactive elements (play button, active song, liked tracks).


Layout:
CSS Grid was used for the overall page structure (content area + fixed bottom player bar) and for the responsive song grid (`auto-fill, minmax()`), so the number of columns adjusts automatically to screen size. Flexbox was used within components (player controls, now-playing info, search box) for alignment.

User Experience:
The bottom player bar stays fixed and visible at all times so users can control playback from anywhere on the page. Hover states (play button fade-in on song cards) and an active/"now playing" highlight give clear visual feedback about what's currently selected.

CSS media queries and responsive layouts were used to adapt the website according to different screen sizes. On smaller screens, the search box and volume control are hidden/adjusted to keep the player bar usable, and the song grid reflows automatically.
